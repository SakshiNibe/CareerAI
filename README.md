# CareerAI – Smart Career Guidance & Placement Prediction System

CareerAI is a web-based system that helps students choose suitable career paths and predict their placement chances based on their CGPA and technical skills.

## Features

- Student Registration & Login
- Student Profile Management
- Add and Manage Skills
- Career Recommendation
- Placement Prediction
- Student Dashboard

## Technologies Used

- HTML
- CSS
- Python
- Flask
- MySQL
- Pandas
- Scikit-learn
- Random Forest

## Modules

1. Registration & Login
2. Student Profile
3. Skills Management
4. Career Guidance
5. Placement Prediction
